Proof Holdings, operated by LT Telecom, provides API-based identity verification for phone numbers, email addresses, and domains. It enables businesses to obtain signed human approval before actions, delegate authority, and manage domain‑based authorization. Founded in 2015, the service targets telecom operators, AI agents, and developers needing trustworthy proof of control.

**Areas:** Identity · Verification · API · Telecom · AI

## How this profile is made

From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
